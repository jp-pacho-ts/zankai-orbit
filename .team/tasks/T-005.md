## Objective

Build the complete client-side Kanban experience with Prompt-to-Board AI generation bar, 5 standard columns ("Ideas", "Up Next", "In Motion", "Waiting", "Complete"), fluid drag & drop via `@hello-pangea/dnd`, task detail right-sliding drawer with "Ask Orbit" AI breakdown and checklist progress, and bottom-center floating 25-minute Pomodoro focus timer.

## Requirements

1. **AI Prompt Bar (`src/components/ai-bar/`):**
   - Prominent prompt bar with placeholder: *"✨ Ask AI to create a board..."*
   - Interactive quick-start idea chips (e.g. "Launch a podcast", "Home renovation", "Exam study schedule").
   - Connects to `/api/ai/generate-board`, displays graceful loading animation, and instantiates the generated board into state.
2. **5-Column Kanban Board (`src/components/kanban/`):**
   - Standard 5 columns: "Ideas", "Up Next", "In Motion", "Waiting", and "Complete".
   - Fluid touch-ready drag-and-drop across columns and within columns using `@hello-pangea/dnd`.
   - Task card component featuring:
     - Color-coded category badge.
     - Title and optional description snippet.
     - Priority badge (`low` | `medium` | `high`).
     - Due date badge with status color coding (overdue, due today, upcoming).
     - Checklist progress indicator bar (e.g. "3/5 items").
     - Assignee avatar.
     - Card dropdown menu with Edit, Duplicate, and Delete actions.
3. **Task Detail Drawer (`src/components/drawer/`):**
   - Smooth slide-in drawer from the right screen edge.
   - Editable title and rich description area.
   - Column selector, priority dropdown, and due date calendar picker.
   - Interactive checklist manager: add items, check off completed subtasks, and delete items.
   - *"Ask Orbit"* AI breakdown button calling `/api/ai/breakdown-task` to automatically populate subtasks.
   - *"Copy summary"* button that copies formatted task summary to clipboard with user feedback toast.
4. **Floating Focus Timer (`src/components/timer/`):**
   - Bottom-center floating pill widget.
   - 25-minute Pomodoro countdown timer with start, pause, resume, and reset.
   - Optional task selector to link active focus time to a specific task.
   - Logs completed sessions into Supabase `focus_sessions` table with duration and timestamp.
5. **State Management (`src/stores/`):**
   - Zustand store powering optimistic board updates, drag reordering, active board switching, drawer selection, and timer synchronization.
6. **Consumer-First Tone:**
   - Ensure all microcopy, toasts, and empty states speak to everyday people and students without technical terms.

## Acceptance criteria

- [ ] AI prompt bar calls `/api/ai/generate-board` and instantiates boards smoothly.
- [ ] 5 columns render and support drag-and-drop card reordering via `@hello-pangea/dnd`.
- [ ] Task detail drawer opens from the right with editable fields and interactive checklists.
- [ ] "Ask Orbit" button triggers `/api/ai/breakdown-task` and appends generated checklist subtasks.
- [ ] Floating focus timer runs a 25-minute countdown and logs completed sessions to `focus_sessions`.
- [ ] Checklist progress is reflected visually on task cards.
