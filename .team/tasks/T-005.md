## Objective

Build the complete interactive consumer Kanban experience strictly following the canonical layout, styling, and Lucide React icons in `docs/reference/ZankaiOrbitDashboard.tsx`: Prompt-to-Board AI input bar, 5 columns ("Ideas" ✳, "Up Next" ◯, "In Motion" ◐, "Waiting" ◈, "Complete" ✓), Board and List view toggling, fluid drag & drop via `@hello-pangea/dnd`, task cards with priority badges (`Urgent`, `High`, `Normal`, `Low`), right-sliding task detail drawer with "Ask Orbit" AI breakdown and checklist management, and floating bottom-center focus timer with session logging.

## Requirements

1. **Canonical Blueprint Alignment (`docs/reference/ZankaiOrbitDashboard.tsx`):**
   - The UI layout, styling classes, and Lucide React icons must strictly follow the reference component in `docs/reference/ZankaiOrbitDashboard.tsx`.
   - Support both "Board" (`LayoutGrid` icon) and "List" (`List` icon) view modes with identical task data.
2. **AI Prompt Bar & Search/Filter Strip:**
   - Universal prompt bar calling `/api/ai/generate-board`.
   - Search bar (`Search` icon) filtering tasks by title and category in real time.
   - Category filter dropdown (`Filter` icon) dynamically listing task categories.
   - Board status strip with total task count, update indicator, team avatar stack, and view toggle.
3. **5-Column Kanban Board (`src/components/kanban/`):**
   - 5 columns with canonical symbols: "Ideas" `✳`, "Up Next" `◯`, "In Motion" `◐`, "Waiting" `◈`, "Complete" `✓`.
   - Column counter pill badges and quick `+` add task buttons.
   - Fluid touch-friendly drag-and-drop across and within columns using `@hello-pangea/dnd`.
   - Task cards matching canonical styling: category badge, card options menu (`...`), task title button, priority badge (`Urgent`, `High`, `Normal`, `Low`), due date with `CalendarDays` icon, assignee avatar, and checklist progress bar (green `#40bfa6` when in "Complete" stage).
4. **Task Detail Drawer (`src/components/drawer/`):**
   - Right-side sliding modal (`min(480px, 100vw)`) with `✦ TASK DETAILS` header and close button (`X`).
   - Title editable input, priority select, and stage select dropdowns.
   - Overview notes textarea.
   - Interactive to-dos checklist: completed status toggles strikethrough, custom styled checkboxes, add-step input form.
   - Due date input with `CalendarDays` icon and assignee select with user avatar.
   - "Start focus session" button.
   - Drawer footer: "Ask Orbit" button (`Sparkles`) triggering `/api/ai/breakdown-task` to append AI-suggested steps, and "Copy summary" button (`Copy`) copying structured summary to clipboard with toast notification.
5. **Floating Focus Timer (`src/components/timer/`):**
   - Fixed bottom-center glassmorphism pill (`backdrop-filter: blur(15px)`).
   - Pulsing glow dot (`.glow`), active task title label, tabular-nums clock (`HH:MM:SS`), and pause/resume button.
   - Logs completed sessions into Supabase `focus_sessions` table with duration and timestamp.
6. **State Management (`src/stores/`):**
   - Zustand store managing active board, column ordering, task list, search query, category filter, active drawer task, and timer state with optimistic UI updates.

## Acceptance criteria

- [ ] UI layout and visual appearance match `docs/reference/ZankaiOrbitDashboard.tsx` with high fidelity.
- [ ] 5 columns render canonical symbols (`✳`, `◯`, `◐`, `◈`, `✓`), counts, and drag-and-drop reordering.
- [ ] Board / List view switcher toggles between 5-column grid and responsive list.
- [ ] Task detail drawer opens with editable fields, interactive checklist items, and "Ask Orbit" AI breakdown.
- [ ] "Copy summary" button formats task details and copies to clipboard with toast confirmation.
- [ ] Floating focus timer operates at bottom-center with pause/resume and logs sessions to Supabase.
