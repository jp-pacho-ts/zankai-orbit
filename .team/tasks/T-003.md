## Requirements

1. **Canonical Reference Alignment (`docs/reference/ZankaiOrbitDashboard.tsx`):**
   - The layout, styling, and HTML structure must strictly follow the reference code in `docs/reference/ZankaiOrbitDashboard.tsx`.

2. **Framework & Typography Setup:**
   - Configure Next.js 15 App Router with TypeScript strict mode.
   - Configure Montserrat font from `next/font/google` applied globally across all elements.
   - Set up CSS variables in `src/app/globals.css` matching the exact palette tokens:
     - Light: `--bg: #f7faff`, `--top: #fff`, `--panel: #f0f5fc`, `--card: #fff`, `--line: #dce7f5`, `--text: #12203a`, `--muted: #7689a7`, `--soft: #eaf2fd`, `--blue: #2867e8`, `--blue2: #438ff4`, `--shadow: #1a4c9512`.

3. **App Shell Components (`src/components/layout/`):**
   - Author top navigation bar with:
     - Brand mark with circular gradient `linear-gradient(145deg, #7ec5ff, #2f68e9)` with planetary ring (`rotate(-34deg)`), `✦`, and italic text `ZANKAI ORBIT`.
     - Workspace selector dropdown ("Northstar Team" with "N" badge).
     - Live status indicator with pulsing glow dot ("Everything in motion").
     - Theme toggle button with smooth icon transition (`Moon` / `Sun`).
     - Notifications button (`Bell`) and Settings button (`Settings2`).
     - User profile avatar displaying user initials or avatar image with owner details.
4. **Base UI Primitives & Responsive Layout:**
   - Implement base primitives and responsive rules matching the reference media queries (`1250px` tablet overflow, `760px` mobile layout, and `prefers-reduced-motion`).
5. **Consumer Tone & Non-Developer Voice:**
   - Ensure all placeholder copy, tooltips, and labels are written for everyday consumers and students. Never use developer jargon, Git terms, or API technicalities.
