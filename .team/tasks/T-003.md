## Objective

Bootstrap the Next.js 15 application shell with Montserrat typography, Tailwind CSS & shadcn/ui design tokens, pale blue and dark navy theme system based on design reference `keen-house-7963`, top application header, workspace selector, live status indicator, and theme switcher.

## Requirements

1. **Framework & Typography Setup:**
   - Configure Next.js 15 App Router with TypeScript strict mode.
   - Configure Montserrat font from `next/font/google` applied globally across all elements.
   - Set up Tailwind CSS with CSS variables for theme support and utility classes (`clsx`, `tailwind-merge`).
2. **Color Palette & Theme Mode (Reference: `keen-house-7963`):**
   - Implement light mode: Pale blue page background, clean white cards, subtle blue-gray borders, vibrant blue primary buttons.
   - Implement dark mode: Coordinated dark navy background, sleek surface cards, clear contrast.
   - Integrate working theme provider (`next-themes` or custom) with smooth transition toggle.
3. **App Shell Components (`src/components/layout/`):**
   - Author top navigation bar with:
     - Brand logo and name: "Zankai Orbit".
     - Workspace selector dropdown showing active board with emoji and title.
     - Subtle pulsing status indicator ("Orbit Live").
     - Light/Dark mode toggle with smooth icon animation.
     - User profile avatar displaying user initials or avatar image and tier badge (`Free` / `Pro`).
4. **Base UI Primitives (`src/components/ui/`):**
   - Provide essential shadcn/ui styled primitives: Button, Dialog/Modal, DropdownMenu, Avatar, Badge, Input, Skeleton, Tooltip, and Progress bar.
5. **Consumer Tone & Non-Developer Voice:**
   - Ensure all placeholder copy, tooltips, and labels are written for everyday consumers and students. Never use developer jargon, Git terms, or API technicalities.

## Acceptance criteria

- [ ] Next.js 15 App Router project structure boots and builds cleanly.
- [ ] Montserrat font family renders across all headings, body text, and buttons.
- [ ] Theme switcher toggles between pale blue light palette and dark navy palette with persistent preference.
- [ ] Header renders brand title, workspace selector, pulsing live indicator, theme toggle, and profile avatar.
- [ ] Reusable UI components conform to the brand design and accessibility standards.
