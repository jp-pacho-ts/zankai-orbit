## Objective

Create Supabase database triggers to automatically provision a user profile and an initial starter board upon new user signup in `auth.users`, ensuring seamless onboarding and strict RLS tenant isolation.

## Requirements

1. **Auto-Profile Trigger (`supabase/migrations/`):**
   - Create a trigger on `auth.users` (`AFTER INSERT`) that automatically creates a corresponding row in `public.profiles` (`id = NEW.id`, `email = NEW.email`, `display_name = COALESCE(NEW.raw_user_meta_data->>'full_name', split_part(NEW.email, '@', 1))`, default `tier = 'free'`).
2. **Initial Starter Board Creation Trigger:**
   - Create a trigger or function to provision a starter board ("My First Orbit") with the 5 standard columns ("Ideas", "Up Next", "In Motion", "Waiting", "Complete") and a friendly welcome task for newly registered users.
3. **RLS Verification:**
   - Ensure RLS policies on `profiles`, `boards`, `columns`, `tasks`, `checklist_items`, and `focus_sessions` strictly restrict access to `auth.uid() = user_id`.
4. **Client Auth Helpers (`src/lib/supabase/`):**
   - Provide client-side auth utility methods for `signInWithOtp`, `signInWithOAuth`, `signOut`, and `getUserProfile`.
5. **Verification:**
   - Run `npx tsc --noEmit` and `npm run build`.

## Acceptance criteria

- [ ] New migration file created in `supabase/migrations/` with `on_auth_user_created` trigger.
- [ ] Auto-creates `profiles` row and default starter board upon signup.
- [ ] RLS policies verified to prevent cross-tenant data leakage.
- [ ] Type check and build succeed cleanly.
