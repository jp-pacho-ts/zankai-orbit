## Objective

Implement server-side API routes and services using the `@google/genai` SDK and Gemini 2.5 Flash with structured JSON schemas for automated "Prompt-to-Board" generation and "Ask Orbit" task breakdown, incorporating user generation quotas and secure server-only key handling.

## Requirements

1. **Gemini SDK Setup (`src/server/ai/`):**
   - Initialize Google Gen AI client using `@google/genai` with model `gemini-2.5-flash`.
   - Read `GEMINI_API_KEY` strictly from server environment variables; never expose to client bundles.
   - Configure structured outputs via `responseSchema` for guaranteed JSON structure.
2. **Prompt-to-Board Route (`src/app/api/ai/generate-board/route.ts`):**
   - Accept `{ prompt: string, theme?: string }`.
   - Verify user authentication and check quota (`ai_monthly_generations < max_ai_generations`). Return consumer-friendly upgrade prompt when quota is reached.
   - Use system prompt tailored for everyday consumers, students, and creators to convert ideas into actionable Kanban projects.
   - Structured JSON output schema must produce:
     - `title`: Creative, clear project title.
     - `emoji`: Fitting emoji icon.
     - `colorTheme`: Palette theme string.
     - `tasks`: Array of tasks with `title`, `description`, target column (one of "Ideas", "Up Next", "In Motion", "Waiting", "Complete"), `priority` ("low" | "medium" | "high"), and `checklist` (array of subtask strings).
   - Increment user's `ai_monthly_generations` count upon successful generation.
3. **Ask Orbit Task Breakdown Route (`src/app/api/ai/breakdown-task/route.ts`):**
   - Accept `{ taskId: string, taskTitle: string, taskDescription?: string }`.
   - Call Gemini 2.5 Flash to generate 3 to 6 concrete, bite-sized actionable checklist steps and an encouraging executive summary.
   - Return structured JSON response `{ subtasks: Array<{ title: string }>, summary: string }`.
4. **Security & Validation:**
   - Validate incoming payloads with Zod schemas.
   - Mask internal errors: return polite, consumer-friendly messages without developer jargon or stack traces.
   - Update `.env.example` to document `GEMINI_API_KEY`.

## Acceptance criteria

- [ ] `/api/ai/generate-board` route returns structured board and task data matching the Gemini schema.
- [ ] User generation quota is validated against the profile record and incremented.
- [ ] `/api/ai/breakdown-task` returns structured checklist items and a helpful summary.
- [ ] Server environment variable `GEMINI_API_KEY` is documented in `.env.example` and kept off the frontend.
- [ ] Error responses are clean, helpful, and free of developer jargon.
