## Objective

Implement Next.js App Router session middleware using `@supabase/ssr` to refresh cookies on incoming requests, implement OAuth and magic link callback handlers (`/auth/callback`), and protect AI route handlers with real authenticated session resolution.

## Requirements

1. **Next.js Session Middleware (`src/middleware.ts`):**
   - Connect `updateSession` using `@supabase/ssr` to ensure session cookies are kept fresh across requests.
   - Configure matcher to exclude static assets (`_next/static`, `_next/image`, `favicon.ico`).
2. **Auth Callback Route Handler (`src/app/auth/callback/route.ts`):**
   - Handle code exchange (`supabase.auth.exchangeCodeForSession(code)`) for OAuth and email magic link redirects.
   - Redirect users back to origin on success or an error query param on failure.
3. **AI Route Handler Session Verification:**
   - Update `/api/ai/generate-board` and `/api/ai/breakdown-task` to verify session using `@supabase/ssr` server client.
   - Fall back gracefully to mock preview limits when unauthenticated.
4. **Verification:**
   - Run `node --test src/server/ai/handlers.test.mjs`.
   - Run `npx tsc --noEmit` and `npm run build`.

## Acceptance criteria

- [ ] `src/middleware.ts` configured with `@supabase/ssr` session refresher.
- [ ] `/auth/callback` route exchanges auth codes cleanly.
- [ ] AI route handlers resolve authenticated user identity from cookies.
- [ ] Backend test suite passes cleanly.
- [ ] TypeScript check and build exit with code 0.
