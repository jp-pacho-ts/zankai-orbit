## Objective

Implement Next.js session boundary proxy/middleware using `@supabase/ssr` to keep cookies refreshed across requests, build the `/auth/callback` code exchange handler, and verify authenticated sessions in AI route handlers in strict accordance with ADR-002.

## Requirements

1. **Next.js Session Request Boundary (`src/proxy.ts` / `src/middleware.ts`):**
   - Connect `updateSession` from `src/lib/supabase/middleware.ts` at the root request boundary to refresh cookies.
   - Support Next.js 16 conventions (`src/proxy.ts` exporting `proxy`, or `src/middleware.ts` exporting `middleware` compatible with current Next.js runtime).
   - Matcher config: intercept all application routes while strictly excluding `_next/static`, `_next/image`, `favicon.ico`, and static assets.
2. **Auth Callback Route Handler (`src/app/auth/callback/route.ts`):**
   - Implement `GET` handler that extracts `code` or `token_hash`.
   - On OAuth `code`: call `supabase.auth.exchangeCodeForSession(code)`.
   - On email `token_hash`: call `supabase.auth.verifyOtp({ token_hash, type: 'email' })`.
   - Validate any `next` redirect target to ensure it is a same-origin relative path (prevent open redirect attacks).
   - Redirect to landing page on success, or friendly error redirect on failure.
3. **AI Route Handler Session Verification (`src/app/api/ai/`):**
   - In `/api/ai/generate-board` and `/api/ai/breakdown-task`, verify caller identity using cookie-backed `auth.getUser()`.
   - Maintain the ADR-001 contract: return a friendly HTTP 401 when no authenticated user is present.
4. **Verification:**
   - Run `node --test src/server/ai/handlers.test.mjs`.
   - Run `npx tsc --noEmit` and `npm run build`.

## Acceptance criteria

- [ ] Root session proxy/middleware refreshes cookies across requests.
- [ ] `/auth/callback` route exchanges OAuth codes and email tokens cleanly with relative redirect protection.
- [ ] AI route handlers enforce authenticated identity with friendly 401 fallback.
- [ ] Backend test suite passes cleanly.
- [ ] Production build and TypeScript type check pass cleanly.
