## Objective

Execute integrated end-to-end verification across Frontend, Backend, and Data layers for Zankai Orbit to ensure production build stability, smooth Kanban drag & drop, reliable Gemini AI board generation, working Pomodoro focus timer, robust Supabase RLS security, and a polished consumer user experience free of developer jargon.

## Requirements

1. **Automated Builds & Code Quality Verification:**
   - Execute and verify Next.js production build (`npm run build`).
   - Execute and verify TypeScript strict type checking (`npx tsc --noEmit`).
   - Execute and verify ESLint checks (`npm run lint`).
   - Never claim a command passed unless it was executed and exited cleanly; report any unrun checks as `not run`.
2. **Integrated Functional Workflows:**
   - Validate Prompt-to-Board AI generation: verify prompt input sends structured request to `/api/ai/generate-board` and instantiates the board with tasks and checklists.
   - Validate 5-column Kanban drag & drop: test task card movement within columns and between columns ("Ideas", "Up Next", "In Motion", "Waiting", "Complete").
   - Validate Task Detail Drawer: test field editing, checklist item completion, "Ask Orbit" AI subtask breakdown (`/api/ai/breakdown-task`), and "Copy summary" clipboard functionality.
   - Validate Floating Focus Timer: test 25-minute Pomodoro countdown, pause/resume controls, and logging into `focus_sessions`.
3. **Design, Accessibility & Consumer Tone:**
   - Validate Montserrat font application across all UI components.
   - Validate Light (pale blue) and Dark (dark navy) theme transitions and visual contrast.
   - Confirm complete exclusion of developer jargon, Git controls, or technical error messages across all pages, modals, and toasts.
4. **Security & Data Isolation:**
   - Confirm Row Level Security (RLS) restricts data access to `auth.uid() = user_id`.
   - Confirm server-only protection of `GEMINI_API_KEY` (no exposure in client bundle or network responses).
5. **QA Handoff Report:**
   - Compile comprehensive verification log in `.team/handoffs/T-006-qa-to-coordinator.md`.

## Acceptance criteria

- [ ] Next.js build, TypeScript check, and linting pass with zero errors.
- [ ] End-to-end Prompt-to-Board AI generation creates full 5-column boards.
- [ ] Drag-and-drop operations operate reliably across all columns.
- [ ] Task detail drawer and "Ask Orbit" task breakdown execute smoothly.
- [ ] Floating focus timer records completed sessions properly.
- [ ] Light and dark modes render with high visual polish matching design guidelines.
- [ ] Zero developer jargon or raw error traces are visible in the user interface.
