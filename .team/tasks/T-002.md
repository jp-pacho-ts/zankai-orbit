## Objective

Create the PostgreSQL database schema in Supabase with all 6 core tables, strict Row Level Security (RLS) policies protecting user data, default column triggers, seed data, and typed Supabase client utilities.

## Requirements

1. **Database Schema & Migrations (`supabase/migrations/`):**
   - Implement tables according to `.team/PROJECT.md`:
     - `profiles`: `id` (PK, references `auth.users`), `email`, `display_name`, `avatar_url`, `tier` (`'free'` | `'pro'`), `ai_monthly_generations`, `max_ai_generations`, `created_at`.
     - `boards`: `id` (PK, UUID), `user_id` (references `profiles`), `title`, `emoji`, `color_theme`, `sort_order`, `created_at`.
     - `columns`: `id` (PK, UUID), `board_id` (references `boards`), `title`, `sort_order`, `created_at`.
     - `tasks`: `id` (PK, UUID), `column_id` (references `columns`), `board_id` (references `boards`), `user_id` (references `profiles`), `title`, `description`, `priority` (`'low'` | `'medium'` | `'high'`), `due_date`, `sort_order`, `created_at`.
     - `checklist_items`: `id` (PK, UUID), `task_id` (references `tasks`), `title`, `is_completed`, `sort_order`.
     - `focus_sessions`: `id` (PK, UUID), `user_id` (references `profiles`), `task_id` (references `tasks`), `duration_minutes`, `completed_at`.
2. **Row Level Security (RLS):**
   - Enable RLS on all 6 tables without exception.
   - Author policies ensuring `auth.uid() = user_id` for profiles, boards, tasks, and focus sessions.
   - Enforce cascaded board ownership policies for `columns` and `checklist_items`.
3. **Database Triggers & Seed Data:**
   - Create trigger to automatically insert a profile row when a new user signs up in `auth.users`.
   - Create trigger or function to seed the standard 5 columns ("Ideas", "Up Next", "In Motion", "Waiting", "Complete") whenever a new board is created.
   - Provide `supabase/seed.sql` with mock consumer boards, tasks, and checklist items.
4. **Supabase Client Setup (`src/lib/supabase/`):**
   - Setup SSR-ready browser, server, and middleware Supabase client factories using `@supabase/ssr` and `@supabase/supabase-js`.
   - Provide client-side typed helper functions for boards, tasks, and focus session logging.
5. **Environment Configuration:**
   - Add `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` to `.env.example`.

## Acceptance criteria

- [ ] Migration SQL file exists under `supabase/migrations/` creating all 6 tables with foreign keys and check constraints.
- [ ] RLS policies are defined and documented for all tables preventing cross-user data leakage.
- [ ] Default 5 columns are automatically created upon board insertion.
- [ ] Supabase client helper modules implemented in `src/lib/supabase/client.ts` and `src/lib/supabase/server.ts`.
- [ ] `.env.example` is updated with all Supabase connection variables.
